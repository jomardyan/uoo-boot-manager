Uoo on Windows 11

A native WPF desktop for Windows Boot Manager's BCD store and local UEFI registrations.

Requirements

  • Windows 11, build 22000 or later (x64 or ARM64). The installer includes the .NET runtime.
  • Administrator approval through UAC for live changes.
  • UEFI firmware features need UEFI boot mode; repair needs a verified local GPT/FAT32 system partition.

What Uoo manages on Windows

PageWhat you can do
Windows bootDefault Windows installation, boot order, timeout, menu visibility, one-time selection; rename, copy, and remove supported loader entries.
Entry optionsSafe mode, alternate shell, boot log, driver names, base video, recovery, graphical or legacy boot menu.
FirmwareUEFI order and inclusion, one-time selection, registration of an existing local EFI loader.
BackupsPrivate BCD and firmware backups, integrity inspection, restore, and typed JSON import and export.
Dual bootFind Linux EFI loaders on the system partition, register an unregistered loader in UEFI, add an excluded Linux entry back, and optionally start the Linux menu first.
DiagnosticsRunning Windows loader, administrator access, boot mode, Secure Boot, BitLocker, and repair prerequisites.
RepairRebuild the running Windows installation's UEFI boot files with BCDBoot on a verified system partition.

Uoo exposes typed options only. It does not run arbitrary BCDEdit commands or scripts.

BitLocker

Uoo reports BitLocker protection before boot changes and requires you to acknowledge that you have your recovery key when protection is on or its state cannot be read. It does not suspend BitLocker, disable Secure Boot, enable test signing, or restart your PC. See BitLocker and encrypted disks for how to find your key and suspend protection for a planned change.

Administrator access and the helper

The desktop runs under your normal account. System changes use a fixed administrator helper installed under C:\Program Files\Uoo Boot Manager, reached through an authenticated local pipe. Uoo rejects administrator actions from user-writable installations, so use the installer, not the portable ZIP, for live changes. The ZIP supports the demo and read-only inspection.

Backups and uninstalling

Backups are private and stored under %ProgramData%\Uoo\BootManager. Uninstalling the app keeps them and keeps any boot settings you applied. Installing and uninstalling never modify boot configuration.

Limits

  • Windows Boot Manager cannot load Linux kernels or draw a custom background like GRUB. Register an existing local Linux EFI loader to select an installed Linux bootloader.
  • Uoo does not edit Ubuntu's GRUB configuration from Windows.
  • The running, default, and last Windows loaders and the Windows Boot Manager firmware entry are protected from deletion.
  • Legacy BIOS, offline Windows repair, and unsupported storage layouts are not presented as verified repair targets.
  • Windows packages are currently unsigned.

Full details: Windows guide on GitHub.

⚠

Encrypted disk? Have your recovery key first.

Before changing boot settings on a BitLocker or LUKS system, find your recovery password or passphrase and keep a copy on another device. Read the encrypted-disk guide.
