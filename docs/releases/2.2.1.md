# Uoo Boot Manager 2.2.1

This maintenance release improves boot configuration handling and package
validation across Linux and Windows.

## Changes

- GTK advanced and appearance settings now submit only the fields you edited,
  preserving unrelated GRUB settings. Configuration read failures receive
  clearer feedback.
- Windows boot configuration cloning and editing share a consistent model.
  Boot entry identifiers require exact braced GUIDs, boot operations use
  explicit JSON field names, and safe mode includes Directory Services Repair.
- Additional regression coverage exercises configuration changes, backups,
  firmware settings, and operation validation.
- Debian source packaging supports preparing PPA uploads for compatible Ubuntu
  releases. The same Debian binary package is checked on Ubuntu 24.04, 26.04,
  and 26.10.
- The landing page and README include Ubuntu PPA installation commands.
  WinGet manifest tooling and submission instructions are available; the
  package has not yet been published in the community WinGet catalog.
- Release publication verifies every expected package against its SHA256
  manifest before publishing. Release builds also request disposable Ubuntu
  UEFI, Secure Boot, and BIOS integration checks.

## Downloads

Windows 11 installers and portable ZIPs are available for x64 and ARM64.
Linux packages include Debian, Fedora and openSUSE RPM, Arch, and x64/ARM64
AppImage, Flatpak, and Snap downloads. Verify downloads using `SHA256SUMS`
or `SHA256SUMS-Windows`.

Windows binaries are currently unsigned. Administrator operations require the
installed native helper. Ubuntu is the supported GRUB management backend;
other package formats do not imply boot repair support on every distribution.
Installing or trying the demo does not automatically change boot settings.
