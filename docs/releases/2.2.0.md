# Uoo Boot Manager 2.2.0

This release brings a consistent application identity, a complete build
interface, and dependency setup for Linux and Windows development.

## Highlights

- A new SVG icon family, platform-native Windows and Linux icons, macOS icon
  exports, browser favicons, and refreshed documentation screenshots.
- Application branding in the GTK and Windows desktop headers, Windows
  executables and installer, and every Linux package format.
- A colorful Makefile covering package builds, validation, demo launch,
  portable Windows tests, and disposable Linux VM checks.
- `make deps` and focused `deps-<target>` commands for missing dependencies,
  including .NET 10, PowerShell 7, AppImage bundling, Flatpak SDKs, and
  Snapcraft. Previews are available through `DEPS_ARGS=--dry-run`.
- Windows ZIP cross-builds now work with plain `make windows` on Linux.
  Windows hosts continue to build the ZIP and Inno Setup installer, with
  installer prerequisite checks before output files are replaced.
- MIT licensing and attribution included in native and portable packages.
- A responsive product landing page with Fluent-inspired controls and the
  same application branding.

## Downloads

Windows 11 installers and portable ZIPs are available for x64 and ARM64.
Linux downloads include Debian, Fedora/openSUSE RPM, Arch, AppImage, Flatpak,
and Snap. AppImage, Flatpak, and Snap include x64 and ARM64 builds.
Use the supplied SHA256 manifests to verify the packages.

Windows packages are currently unsigned. Administrative actions require the
installed helper. Ubuntu remains the supported GRUB management backend;
availability of a package for another distribution does not establish boot
repair support there. macOS icons are design exports, not a macOS app build.

No application installation changes the boot configuration automatically.
Changes remain explicit, authenticated actions inside Uoo.
