Frequently asked questions

Short answers about safety, licensing, supported systems, and where Uoo keeps its data.

Is Uoo free?

Yes. Uoo is open source under the MIT License. You can use, modify, and redistribute it.

Will Uoo restart my computer?

No. Uoo never reboots automatically. Scheduled one-time boots take effect the next time you restart.

Can a change leave my computer unable to start?

Any boot change carries risk. Uoo validates requests, backs up first, verifies the result, and rolls back when a tool fails. It cannot recover a failed disk or guarantee recovery from power loss in the middle of a change, so keep recovery media and, on encrypted systems, your recovery key.

What does "Fix dual boot" do?

It checks how Ubuntu and Windows start and offers only the fixes Uoo can make safely: showing a hidden GRUB menu, adding Windows to GRUB, registering Ubuntu or another Linux loader in the UEFI firmware, and fixing the startup order. You choose each step, Uoo backs up first, and it never restarts your computer. It does not change encryption, Secure Boot, partitions, or the clock, and it cannot fix every dual-boot problem. See encrypted systems for how it behaves with BitLocker.

Which Linux distributions are supported?

Ubuntu 24.04+ is the verified GRUB backend. Fedora, openSUSE, and Arch packages provide the desktop, demo, and available inspection, but GRUB changes and repair are not established there. See Uoo on Ubuntu.

Can the Windows app edit Linux's GRUB, or the Linux app edit Windows?

No. Each edition manages its own platform's boot tools: Windows Boot Manager and BCD on Windows, GRUB and UEFI on Ubuntu. To start Linux from Windows Boot Manager, register an existing Linux EFI loader as a local firmware entry.

Why do the Snap, Flatpak, and AppImage builds not change my system?

They provide the desktop and demo. Authenticated system changes need the matching native package, which installs the root-owned helper and polkit policy.

Why does Windows warn about the installer?

Current Windows packages are not code-signed, so SmartScreen shows an unknown-publisher warning. Download from the official GitHub release and check the SHA256 manifest. Code signing is being evaluated.

Where are backups stored?

On Ubuntu in /var/lib/uoo-boot-manager/backups; on Windows under %ProgramData%\Uoo\BootManager. Both are private to administrators, and removing the app does not delete them on Windows.

Is Uoo on WinGet?

Not yet. A listing is in preparation; use the installer from the release page for now.

How do I report a bug or a security problem?

Open a GitHub issue for bugs; include your version, platform, and boot mode, and never paste recovery keys. Report vulnerabilities privately as described in the security policy.
