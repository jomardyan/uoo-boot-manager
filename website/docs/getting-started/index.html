Getting started

Install Uoo, try it in demo mode, and apply a first boot change with a recovery path.

Install on Ubuntu

Ubuntu 24.04 or newer with GTK 4.6+ and libadwaita 1.5+ is required. The package installs Python, PyGObject, GTK4, libadwaita, and polkit.

Use the PPA for updates through APT. First confirm that Launchpad has published a successful build for your Ubuntu codename (lsb_release -cs), then run:

sudo add-apt-repository ppa:mastercrypt/uoo
sudo apt update
sudo apt install uoo-boot-manager

If the build for your release is still queued, download uoo-boot-manager_2.2.1_all.deb from the latest release and run sudo apt install ./uoo-boot-manager_2.2.1_all.deb. Start it from the application menu or with uoo-boot-manager. Installing never changes boot settings.

Install on Windows 11

Download windows-x64-setup.exe (Intel or AMD) or windows-arm64-setup.exe (Windows on Arm) from the latest release, run the installer, and open Uoo Boot Manager from Start. Windows 11 build 22000 or later is required and the .NET runtime is included. Current Windows packages are unsigned, so SmartScreen may warn you; verify the download against the published SHA256SUMS-Windows file.

A WinGet listing is being prepared and is not yet in the community catalog.

Try the demo first

Demo mode uses sample boot entries and changes nothing on your computer.

# Ubuntu (installed package)
uoo-boot-manager --demo

# Windows (PowerShell)
& 'C:\Program Files\Uoo Boot Manager\Uoo.BootManager.exe' --demo

Making your first change

  1. Check for encryption. If the system drive uses BitLocker or LUKS, follow the encrypted-disk guide first.
  2. Unlock protected settings. On Ubuntu, use the lock button and authenticate. On Windows, approve the UAC prompt when an operation needs administrator rights.
  3. Edit a draft. Forms, custom entries, and firmware order stay drafts until you apply them; Uoo asks before discarding them.
  4. Apply and review. Each change is validated, backed up, applied, and verified. If a tool fails, Uoo rolls back.
  5. Restart yourself. Uoo never reboots automatically.

Backups appear on the Backups page, where you can inspect, export, and restore them.

⚠

Encrypted disk? Have your recovery key first.

Before changing boot settings on a BitLocker or LUKS system, find your recovery password or passphrase and keep a copy on another device. Read the encrypted-disk guide.
